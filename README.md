# 📝 AI Resume Analyzer with LM Studio Integration

## 📌 Overview
The **AI Resume Analyzer** is a full-stack MERN application designed to help job seekers improve their resumes and prepare for interviews.  
It provides:
- Resume parsing and analysis
- AI-powered suggestions for improvements
- Integrated **LM Studio Assistant** for offline interview practice and career guidance

---

## 🚀 Features
- **Resume Upload & Analysis**: Upload resumes in PDF/Doc format and get structured insights.
- **AI Assistant (LM Studio)**: Chat with locally hosted models (Mistral, Gemma, LLaMA, etc.) for interview prep and resume feedback.
- **Authentication**: Secure login/signup using JWT.
- **Dashboard UI**: Clean, minimal, professional design with interactive chat panel.
- **Offline AI**: Works without paid APIs, thanks to LM Studio integration.

---

## 🛠 Tech Stack
- **Frontend**: React, CSS (minimal UI styling)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **AI Integration**: LM Studio (local API server)
- **Other Tools**: dotenv, bcrypt, cors
